# Kathmandu Connect: Empowering Community Collaboration

Kathmandu Connect aims to connect citizens with the metropolitan city and empower Community engagement.


## Features

-Authentication and Authorization
-Use of ML to Report Pothole Issues and Tracking 
-Sharing Ideas and Polls
-Creating Events and Managing
-Call for Volunteers
-Relaying Metropolitan Notices
-Use of ML in Collecting Feedbacks and Surveys
-Levelling and Rewards
-Sharing on Social Media
-Information on Public Transport
-Security Concerns
-Use of ML to Recommend Tourist Destinations
-Real-time Forum in Neighbourhoods


## Tech Stack

**FrontEnd:** HTML, CSS, JavaScript,SCSS, BootStrap

**BackEnd:** Django, MySQL


## Originality

The project, as the name suggests, is trageting Kathmandu Metropolitan City and its digital services. 
It is using ML to train the data for precise and fast results. It only lets the citizens to join the site after verifying their citizenship status.
